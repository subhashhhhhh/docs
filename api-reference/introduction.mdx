This section documents the API surface currently used by the Fastlytics web app.

## What this API does

Fastlytics uses a layered API architecture:

- the React frontend sends authenticated requests
- the Cloudflare worker validates tokens, injects the backend API key, and serves cacheable responses
- the FastAPI backend handles data retrieval, tier enforcement, payments, news, and discussion features

## Base URL

Production frontend requests default to:

```txt
https://api.fastlytics.app
```

In local development, the frontend uses `VITE_API_BASE_URL`.

## Important scope note

<Warning>
  This is not yet a stable public developer API with versioned guarantees. It is the internal API contract that powers the current Fastlytics application.
</Warning>
