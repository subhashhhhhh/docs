Use this guide when you want to work on the product, the API stack, or this Mintlify docs site from your machine.

## Prerequisites

- Node.js for the frontend, worker, and docs
- Python for the FastAPI backend
- A `.env` file for the frontend and the backend values you need locally

<Steps>
<Step title="Run the frontend app">

```bash
npm install
npm run dev
```

The frontend dev server runs on `http://localhost:8080`.
</Step>

<Step title="Run the backend API">

From `backend-api/`:

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

The backend serves the FastAPI app locally and powers routes that are not satisfied by cached worker data.

</Step>
<Step title="Run the Cloudflare worker">

From `workers-v2 (new and updated)/`:

```bash
npm install
npm run dev
```

The worker handles request proxying, edge caching, JWT validation, and some premium-route enforcement.
  </Step>

  <Step title="Preview the docs site">

From the docs repository root, install Mintlify's CLI if needed and start the preview:

```bash
npm i -g mint
mint dev
```

The docs preview is available at `http://localhost:3000` by default.
  </Step>
</Steps>

## Useful checks

```bash
# frontend
npm run lint
npm run test:ci

# backend-api
pytest
ruff check .

# docs
mint broken-links
mint validate
```

## Notes

<AccordionGroup>
  <Accordion title="Frontend port" icon="globe">
    The active frontend dev port is `8080`, not `5173`.
  </Accordion>
  <Accordion title="Worker directory name" icon="folder">
    The worker directory contains spaces. Quote the path in shell commands if you are not already inside it.
  </Accordion>
  <Accordion title="Auth in local development" icon="shield">
    The frontend uses Supabase auth. The backend may skip API-key enforcement locally when `FASTLYTICS_API_KEY` is unset, but production traffic normally flows through the worker.
  </Accordion>
</AccordionGroup>
